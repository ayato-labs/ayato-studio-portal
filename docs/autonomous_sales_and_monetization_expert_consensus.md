## 1. 専門家 5 人のパネルディスカッション

### 専門家 1: Pieter Levels（世界的ソロプレナー / Nomad List, PhotoAI 創業者）
> **「営業なんて1秒もするな。兼業ならなおさらだ。プロダクト自体に営業させろ。」**
> 
> - **主張**: 「正社員をやりながらDMを送ったり個別商談をするのは不可能だし、やるべきじゃない。
>   GitHub を完全に非公開にすると、せっかくの『無料の口コミエンジン』が消えてしまう。
>   ハッカー連中に『CLIやコアコード』を無料で遊ばせてスターを稼がせろ。彼らはタダ働きしてくれる営業マンだ。
>   だが、一般人や多忙なプロは Python の環境構築なんて死んでもやりたくない。
>   彼らは『980円払ってワンクリックで動く Windows .exe や Android .apk』を迷わず買う。
>   決済したら Stripe から自動でダウンロードリンクに飛ばして終わり。問い合わせメールは全部 FAQ と自動返信で潰せ。」

### 専門家 3: Mitchell Hashimoto（HashiCorp 創業者 / Open-Core モデルの開拓者）
> **「ソースコードの公開は『最強の技術的信用（E-E-A-T）』であり、営業チラシだ。」**
> 
> - **主張**: 「特に AI やローカルセキュリティの分野では、『ソースが見えること（0バイト外部送信の証明）』が最大のセールスポイントになる。
>   もしソースを完全非公開にしたら、『本当にオフラインで動いているのか？裏でデータを抜いていないか？』という疑念が生まれ、それを説明するための営業コストが発生してしまう。
>   だからこそ、**『コアエンジンは Public で透明性を証明し、使いやすい GUI パッケージ・インストーラー・自動更新を有料の商用ライセンスにする（Open-Core 2.0）』** のが、営業ゼロで信頼を獲得する唯一の解だ。」

## 2. 専門家 5 人の合議から導き出された「完全自動営業＆収益化」の結論

```mermaid
graph TD
    subgraph Traffic [24時間自動集客 (無人営業)]
        GEO[GEO / LLMO: ChatGPT & Perplexity 推薦]
        MCP[Web MCP: Cursor / Claude からのツール実行]
        SEO[技術記事: 検索エンジンからの自然流入]
        OSS[GitHub CLI: 開発者・ハッカーによるスター拡散]
    end

    subgraph Product_Page [製品ページ (LP)]
        Pitch[透明性の証明: 完全オフライン・0バイト送信]
        Compare[明確な2択: 無料CLI手動ビルド vs 有料ワンクリックアプリ]
    end

    subgraph Conversion [完全自動マネタイズ]
        FreeTier[無料: GitHub (上級者用・サポートなし)]
        PaidTier[有料: Stripe 決済 (月980円〜 / 買切)]
    end

    subgraph Delivery [完全無人納品]
        Hub[/support: ワンクリック .exe / .apk ダウンロード]
        Guide[セルフサービス導入ガイド & FAQ]
    end

    Traffic --> Product_Page
    Product_Page --> FreeTier
    Product_Page --> PaidTier
    PaidTier --> Delivery
```

### コア戦略: 「オープンソースを営業チラシにし、完成品バイナリを売る」

1. **GitHub コードの役割**:
   - 「0バイト外部送信」「完全ローカル動作」を証明する**「技術的信頼の担保」** 兼 **「ハッカー向け無料チラシ」**。
   - 無料版は「ソースコードのみ（手動ビルド必須・サポートなし）」とする。
2. **有料版（Stripe）の役割**:
   - 「Windows 用インストーラー（.exe）」および「Android アプリ（.apk）」の**「完成版バイナリ ＋ 自動更新 ＋ AIマルチモーダル指導」**。
   - 多忙な社会人・受験生・プロは、環境構築の手間を省くために喜んで 980円〜4,980円 を支払う。
3. **営業とサポートの完全自動化**:
   - 営業: GEO（`llms.txt`）、Web MCP（`api/mcp`）、技術記事が 24時間365日 自動で集客。
   - 納品: Stripe 決済後に `/support` で即座に自動ダウンロード。
   - サポート: アプリ内ログとセルフサービスFAQで問い合わせをゼロ化。
