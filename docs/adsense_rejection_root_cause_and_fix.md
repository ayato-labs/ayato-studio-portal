## 1. 根本原因の特定（なぜ「有用性の低いコンテンツ」と判定されたのか）

Google AdSense の品質ガイドラインおよびサイト構造を精密に調査した結果、以下の **4つの構造的要因** が重なって却下されたことが判明しました。

## 2. 各要因の詳細と対策

### 要因 1: ドメイン内の完全重複コンテンツ (Duplicate Content)
- **現状**: `src/content/blog/` と `src/content/insights/` に、**同一タイトル・同一本文の記事が11本（全22URL）重複して存在**していました。
- **Googleの判定**: 検索エンジンのクローラーは、同一ドメイン内で同じ文章が複数URLで量産されている状態を「質の低いコンテンツの水増し（Thin Content）」とみなし、即座に不合格判定を下します。
- **対策**: `/blog` を `/insights` に 301 統合し、ドメイン内の全URLで重複を完全にゼロにします。

### 要因 2: 審査巡回時のデータベース休止（空ページ・エラー返却）
- **現状**: 以前 Supabase が Paused（休止）になっていた期間があり、審査ボットが訪問した際に `/reports` などの動的ページが「TypeError: fetch failed」や空表示になっていた可能性が極めて高いです。
- **Googleの判定**: 巡回時にコンテンツが表示されない、またはエラーを返すサイトは「コンテンツの最小要件を満たしていない」として門前払いされます。
- **対策**: 今回 Supabase を完全復旧させ、全160ページがエラーなく 200 OK で静的生成（SSG）される状態を確立しました。

### 要因 3: 自動要約コンテンツに対する Google の厳しい評価
- **現状**: `/reports` の自動生成要約は、他メディアやarXivの要約であるため、Googleから「付加価値のないアグリゲーション（機械的要約）」と見なされやすい性質があります。
- **対策**:
  - Googleクローラーおよび審査員に対し、**「人間が執筆した専門的見解・アーキテクチャ解説（E-E-A-T）が詰まった `/insights`（13本）および `/academy`、`/services`」をサイトのメインコンテンツとして前面に配置**します。

### 要因 4: 著者性・専門性（E-E-A-T）の明示
- **現状**: 記事の執筆者情報が薄く、「誰がどのような専門性を持って執筆・運営しているか」がGoogle評価者に伝わっていませんでした。
- **対策**: 各記事の末尾および `/about` に、Ayato Studio の技術バックグラウンド（AI Harness Engineering、OSS開発実績、GitHubリンク）を明記した「Author Bio（著者ボックス）」を設置します。

## 3. 審査再申請に向けた 4 ステップ実行計画

1. **ステップ 1: `/blog` と `/insights` の重複統合**
   - 重複している `/blog` ルートを `/insights` に正規化し、サイト内リンクもすべて `/insights` に統一。
2. **ステップ 2: 著者プロフィール（Author Box）の設置**
   - `/insights` の全記事末尾に、専門性・経歴を明記した著者カードを配置。
3. **ステップ 3: ナビゲーションの最適化**
   - ヘッダーメニューを「独自記事（Insights）」、「アカデミー（Academy）」、「サービス（Services）」、「AI News」の順に整理し、オリジナルコンテンツを最前面にアピール。
