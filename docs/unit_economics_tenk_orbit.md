# TenKOrbit: 原価試算 & マーケティング・ポジショニング戦略書

## 1. エグゼクティブサマリー

**TenKOrbit** は、「1万時間の法則（The 10,000-Hour Rule）」をベースにした、夢・長期ビジョン（大項目）と資格・マイルストーン（中項目）を週単位・秒単位で正確に管理し、手書きノート写真のOCRとローカルAIによる伴走指導を行う **デスクトップ（Windows/Mac）＆ Android（APK）対応の完全プライベート学習時間管理SaaS** です。

```mermaid

```

## 3. マーケティング・ポジショニング（Moat / 差別化要因）

### ① 大手学習アプリ（Studyplus等）との決定的な違い
1. **完全プライバシー & 広告ゼロ**:
   - SNS機能での他人の視線や不要な広告通知を完全排除。自分の夢と目標だけに集中できる。
2. **手書きノートの「質」をAIが評価**:
   - 単なる時間記録（量）だけでなく、手書きノートや図解を写真で読み取り、「学習の深さ・理解度」をルーブリックに基づいてAIが客観評価。
3. **Android 実機 APK とデスクトップのシームレス両対応**:
   - Flet / Flutter ベースの洗練されたダークモードUIで、机でのPC学習もスマホでの外出先記録も一貫してサポート。
