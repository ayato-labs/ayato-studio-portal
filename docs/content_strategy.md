# Ayato Studio メディア・コンテンツ戦略ガイドライン

## 1. ブランドアイデンティティと戦略目標

本プロジェクト `ayato-studio.ai` は、日本国内のエンジニアおよびビジネスリーダーに向けて、最先端の **「AI技術の専門家」** としての絶対的な権威と信頼を築くための知的情報発信プラットフォームです。

### 1-1. 専門性の深耕ロードマップ
- **インテリジェンス・ハブ**: 本ドメインでは、海外のAI論文（arXiv cs.AI）の日本語超速要約や、最新のAI/LLMニュースをアグリゲートし、「ここを見ればAIのすべてがわかる」状態を作ります。
- **実務・自動化の専門化**: 単なるニュースに留まらず、LLM APIをシステムへ高度に組み込むことによる「これまで自動化できなかった業務プロセスの変革・自律型エージェントの実装」や、AIツールとデータベースを接続する **MCP (Model Context Protocol)** の実践技術にフォーカスします。

### 1-2. サブドメイン戦略（金融×AI）
- **領域特化の切り分け**: 本ドメイン（`ayato-studio.ai`）では純粋なAI技術および自動化の最高峰をアピールします。
- **金融サブドメイン (`finance.ayato-studio.ai`)**: 「金融×AI」に特化した発信領域として定義。AIインテリジェンスを用いた財務分析、EDINET/適時開示情報の解析、マーケット分析レポートの発信など、専門性の高い特化領域として別稼働させ、ターゲットの関心を分散させずに強烈なアピールを行います。

## 2. メディア別の役割と価値

| レイヤー | 媒体 | 配置 / アクセス | 役割 | 収益化 |
| :--- | :--- | :--- | :--- | :--- |
| **Expression (Skin)** | **Blog** | `src/content/blog` | SEO集客・トレンド発信・思想表明 | AdSense / 送客 |
| **Structure (Skeleton)** | **Academy** | `src/content/academy` | 信頼構築・基礎理論の教育 | 権威性 / 基礎力 |
| **Sub-domain (Specialty)** | **Finance Portal** | `finance.ayato-studio.ai` | 金融×AIに特化したマーケット分析 | 特化ブランディング |
| **Heart (Muscle)** | **Note** | (外部 / `product/note`) | **技術資産(コアエンジン)の譲渡** | **直接販売 (有料)** |

### 各メディアの詳細定義
#### Blog: 認知と拡散
- **ターゲット**: 広く浅い潜在層、SNSユーザー。
- **内容**: 「何をしたか(成果)」。プロダクトのアップデート情報、技術トレンドへの見解。MCPなどの活用実践例。

#### Academy: 信頼と定着
- **ターゲット**: Ayato Studio の技術力に信頼を寄せる学習者・エンジニア。
- **内容**: 「なぜそうなるか(理論)」。LLMの仕組み、プロンプトエンジニアリングやシステムアーキテクチャの理論。

#### Finance Portal (サブドメイン): 特化知性の実証
- **ターゲット**: 金融・投資領域のAI利活用に興味があるスペシャリスト・企業。
- **内容**: 金融AIエージェントによる企業開示分析や、マクロ金融動向。

#### Note: 収益と確信
- **ターゲット**: 最速で結果を出したいプロフェッショナル、自律型システムの実装者。
- **内容**: **「いかに実装するか(資産)」。** そのまま動くソースコード（MCPサーバー、GCPデプロイ構成等）、実戦的なデバッグログ。

## 3. コンテンツ配置の判定基準 (Checklist)

新しい知見や記事が発生した際、以下を確認して配置先を決定します。

- [ ] **その記事は「金融や株式投資に特化したAIの分析・要約」か?**
  - YES → **Finance Portal** (サブドメイン)
- [ ] **その記事は「そのまま動くコード・実装テンプレート」が主役か?**
  - YES → **Note** (有料)
- [ ] **その記事は「一過性ではない普遍的な技術理論」か?**
  - YES → **Academy** (無料)
- [ ] **その記事は「最新ニュース、日記、あるいは成果報告」か?**
  - YES → **Blog** (無料)

## 4. 相互リンク(CTA)の運用
すべての無料コンテンツは、関連する有料コンテンツ(Note)がある場合、あるいは特化サブドメインとの親和性がある場合、必ず末尾に誘導文を配置します。

- **Blog末尾**: 実装資産(Note)への誘導、またはMCP関連デモへのリンク。
- **Academy末尾**: 実装テンプレート(Note)への誘導。
