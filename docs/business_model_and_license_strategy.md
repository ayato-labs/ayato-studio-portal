# Ayato Studio: ソフトウェアライセンス戦略 & オープンソース商用化（Open-Core vs クローズド）整合性調査書

## 1. エグゼクティブサマリー

「有料で販売するソフトウェアのコードを GitHub 上で MIT License（完全無料・改変・商用利用自由）で公開していては、ビジネスとして成り立たないのではないか？」という疑問は、**商用ソフトウェア戦略において最も本質的かつ致命的な論点** です。

結論から申し上げますと、現在の状態には**「無料のオープンソース公開」と「有料SaaS販売」の間で明確な機能的・ライセンス的境界線が引かれていないという構造的な整合性の欠如** がありました。

本レポートでは、世界標準の商用モデル（Open-Core / プロプライエタリ）を分析し、Ayato Studio が収益を最大化するための**「3 つの是正アプローチ」** を提示します。

---

## 2. なぜ「全コード Public + MIT」のまま販売すると破綻するのか？

### ① 法的・商業的リスク (MIT License の性質)
- MIT License は「誰でも無償で複製・改変・再配布・商用利用してよい」という極めて寛容なライセンスです。
- これにより、悪意ある第三者があなたのコードをそのままコピーし、別名で安く販売したり、無料で再配布しても法的に一切差し止めることができません。

### ② 購入動機の喪失
- ソースコードと GUI アプリの全機能が Public リポジトリに置かれている場合、開発者や IT リテラシーのある層は「1 円も払わずに `git clone` して無料でフル機能を使う」ことが可能です。

## 3. 世界標準の 3 つの解決モデル比較

```mermaid
graph TD
    subgraph Pattern_A [パターンA: 完全クローズド (推奨)]
        PrivRepo[Private リポジトリ] --> Binary[ビルド済み .exe / .apk]
        Binary --> Stripe[Stripe 決済]
        Stripe --> PaidUser[有料顧客のみ利用可能]
    end

    subgraph Pattern_B [パターンB: Open-Core 分離]
        CoreCLI[Public: 最小CLIエンジン (MIT)] --> Dev[開発者・SEO/GEO集客]
        GUIApp[Private: GUI / Android APK / AI指導] --> Stripe2[Stripe 決済]
    end
```

| モデル | 仕組み | メリット | デメリット | 推奨度 |
| :--- | :--- | :--- | :--- | :--- |
| **パターン A: 完全クローズド（Private化）** | 有料販売するアプリ（MovieToText, TenKOrbit）の GitHub リポジトリを **Private（非公開）** に変更し、完成版バイナリのみを有料販売する。 | **売上の最大化**。コード流出・無料タダ乗りを 100% 遮断。ビジネスモデルが最もシンプルで明確。 | 開発者コミュニティからのコード貢献は受けられない。 | **★★★★★ (最も推奨)** |
| **パターン B: Open-Core 分離モデル** | コアの最小 CLI / ライブラリのみ Public (MIT) で公開し、GUI 版（.exe/.apk）や AI 機能は Private で有料販売する。 | 無料版による強力な SEO/GEO・知名度獲得と、GUI 版でのマネタイズを両立。 | リポジトリを「CLI用」と「GUI/商用版用」の 2 つに分割管理する保守コストが発生。 | **★★★★☆** |
| **パターン C: ソースアベイラブル (BSL/Fair-Code)** | コードは公開するが、商用利用やバイナリ利用には有料ライセンスの購入を法的に義務付ける（Redis, Sentry型）。 | コードの透明性を保ちつつ、無断商用利用を法的に禁止できる。 | 個人利用の無料コンパイルを防ぐ強制力は弱く、ライセンス違反の監視コストがかかる。 | **★★★☆☆** |

## 4. Ayato Studio における即時是正アクション（推奨計画）

1. **主力有料プロダクトの Private（非公開）化**:
   - `ayato-labs/TenKOrbit` および `Transform_MovieToText` のリポジトリを **GitHub 上で Private（非公開）** に切り替える。
2. **製品 LP から「GitHubで無料取得」導線を排除**:
   - `/services/movie-to-text` や `/services/tenk-orbit` の料金表から「GitHubで無料取得（¥0）」ボタンを削除し、**「Pro プラン（月額）」または「Lifetime 買切ライセンス」の有料導線に一本化** する。
3. **`ProjectCodeMap` は Open-Core として活用**:
   - `ProjectCodeMap` のみ、PyPI / CLI（`uvx project-code-map`）を無料公開して世界中から開発者・AI クローラーを集客する「無料フロントエンド（リードマグネット）」として機能させ、Web 版や他プロダクトへ誘導する。
