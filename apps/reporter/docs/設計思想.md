## 概要
本システムの設計思想は以下の3つの柱に基づいています：
1. **AI/Tech Specialization & Japanese-First**: AI・半導体分野に収集ターゲットを絞り、出力レポートを日本語（jp）のみに一本化。多言語生成による余計なAPIコストとレイテンシを排除し、日本の意思決定者への価値提供を最優先とする。
2. **Rebuild Trigger Optimization**: システムの静的エッジ配信を支えるため、`tech` プラグインが正常に新規レポートを処理した時のみ再ビルドをキックする自律型トリガーチェーンを適用。不要なビルド実行をインフラレベルで遮断する。
3. **GCP-Native Professionalism**: GCP（Cloud Run Jobs / Secret Manager）および Supabase の非同期処理（Async/Await）への絶対的適合。ローカルと本番の乖離をなくし、耐障害性とセキュリティを極大化する。
